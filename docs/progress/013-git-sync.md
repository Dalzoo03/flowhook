# 013 — 오늘 작업 Git 반영

기록일: 2026-11-16. 사용자 요청: 오늘까지 한 작업을 GitHub에 반영한다.

## 반영 범위

- JPA 저장 계층과 @Valid @RequestBody 이벤트 요청 DTO.
- Flyway V4 재시도 예약·시도별 이력, 최대5회/backoff/429 Retry-After.
- local 자동 worker·수동 전송 호환·대상 제한.
- Flyway V5 처리 기한/UUID 소유권·UNKNOWN 회수·재예약/최종 실패.
- 관련 테스트와 학습/실습/상태 기록. 이전 작업 기록은 당시 상태로 보존한다.

## 검증 상태

로컬 전체103개 테스트·assemble 성공, 실패·오류·스킵0. 격리된 실제 JVM SIGKILL→재시작→30초 만료 회수→시도2 성공도 확인했다.
코드 변경 이후 추가 동작 변경은 없으므로 업로드 때문에 같은 로컬 테스트를 반복하지 않는다. GitHub CI에서 백엔드 전체 테스트/빌드와 데모 수신기 자체 검증 결과를 확인한다.

기능 커밋 `1dda9de47a506fd73603da0b08377b54387ceab4`를 main에 푸시했다.
[GitHub CI](https://github.com/Dalzoo03/flowhook/actions/runs/43890510044) 성공을 확인했다. 동일 기능 커밋에서 test-and-build(1분51초)와 receiver-test(10초) 모두 성공했다.
CI 성공 링크와 최종 상태 기록을 문서 커밋으로 추가 반영한다. 문서만 바뀌므로 현재 workflow paths 조건에서 새 CI는 실행하지 않는다.

## 제한과 다음 작업

비밀번호/인증/세션 파일·빌드 산출물은 반영하지 않는다. 계정/인증 설정 변경이나 배포는 하지 않는다.
사용자 DB의 V5는 다음 새 버전 앱 재시작에서 적용된다. 구버전 앱을 모두 중지한 뒤 시작한다.
중복 HTTP 가능성이 남으며 수신자의 멱등 처리·인증/서명/외부 송신은 후속이다.
